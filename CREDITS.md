# Credits

Sluger's garden geometry, slug, procedural textures and gameplay were built specifically for this project. The neighbouring Tidewater project was used as a visual and technical reference for vegetation batching, ground detail, atmosphere and environmental audio. Its rendering engine and ocean code are not included.

The Rocketbox licence is included in [public/models/LICENSE-Rocketbox.md](public/models/LICENSE-Rocketbox.md).
