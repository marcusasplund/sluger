# sluger

Ett litet Three.js-spel om en mördarsnigel som glider runt i en trädgård, äter växter och försöker överleva människornas motåtgärder.

## Kom igang

```bash
npm install
npm run dev
```

## Första prototypen

- spelbar snigel med enkel low-angle kamera
- nattlig trädgårdsscen
- växter att äta upp
- en farozon med "kokande vatten"-känsla

## Nästa bra steg

- lägga till människa med patrull-AI
- lägga in riktiga hinder som spade, salt och skor
- ge snigeln stamina, hp eller stealth-system
- byta ut placeholder-modeller mot riktiga assets
